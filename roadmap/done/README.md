# Completed Work

Этот каталог хранит записи о фактически завершённых roadmap tasks. Он не является changelog и не заменяет Agent Notes.

## Naming

Используйте `YYYY-MM-DD-<TASK-ID>-<short-name>.md`, например `2026-09-03-ARCH-001-broker-contract.md`.

## Правила

- Создавайте запись только после выполнения Definition of Done из [WORKFLOW.md](../WORKFLOW.md).
- Используйте [TEMPLATE.md](TEMPLATE.md).
- Указывайте точные выполненные проверки и результат.
- Ссылайтесь на PR, task card, Agent Note и owning documentation.
- Не изменяйте старую запись ради нового поведения; создайте новую follow-up task и новую completion record.
